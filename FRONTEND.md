# Runway Models — фронтенд

Реализация интерфейса по ТЗ репозитория true-adam. Стек: Next.js 16.4.2 (App Router), React 19.3, TypeScript, Material UI 9.5, Bootstrap 5.3. Bootstrap используется для сетки и утилит, MUI — для полей, переключателей, диалогов, вкладок, аккордеонов и мобильного меню. Собственные CSS-стили задают журнальную чёрно-белую композицию. Дополнительного JS-фреймворка и Tailwind нет.

## Запуск

**Быстро на Windows:** дважды нажмите `START-DEV.cmd` в папке проекта. Он при необходимости установит зависимости, выберет свободный порт, запустит Next.js и откроет сайт в браузере. Окно терминала оставьте открытым; остановка — Ctrl+C. Повторное нажатие откроет уже работающий экземпляр.

**Из терминала:** `npm run local` (автоматически открывает браузер) или `npm run dev` (обычный Next.js). `npm run local -- --no-open` запускает без открытия браузера.

Node.js 24 LTS. `npm ci`, затем `npm run dev`. Откройте адрес из терминала (обычно http://localhost:3000).

Проверки: `npm run typecheck`, `npm run lint`, `npm run build`. Сборка — статический экспорт Next.js в `out/`. `npm start` обслуживает готовую сборку на http://127.0.0.1:3000; переменная PORT меняет порт. Динамические страницы заранее генерируются из типизированных демонстрационных данных.

## Что работает

- Главная с переключаемыми фотографиями Chico Lachowski, Jordan Barrett, Sean O’Pry и David Gandy на первом экране; подборки моделей, событий, академии и backstage.
- `/models`: поиск по имени, город, специализация, избранное, пустое состояние и сброс. Шесть портфолио `/models/[id]`, параметры и иллюстративные галереи, переход к приглашению конкретной модели.
- `/events`: поиск, город, тип, начальная дата, сортировка, карточки и календарь с навигацией по месяцам. Восемь страниц событий; завершённые, закрытые и отменённые события не принимают заявки.
- `/shoots`: описание съёмок и условия, связанная заявка. Зрительская запись существует отдельно и только для открытых показов.
- `/casting`: выбранное событие или курс из URL, проверка обязательных полей, email, телефона, роста, фотографий (до 3 JPEG/PNG/WebP, до 5 МБ каждая), согласие, сообщение об ошибке и сохранении черновика.
- `/academy`: три программы, преподаватели, цены, расписания и переход к записи на конкретный курс.
- `/backstage`: фильтры фото и MUI lightbox с клавиатурной навигацией.
- `/contact`: форма подбора модели / приглашения выбранной модели.
- `/login`, `/register`, `/account`: явно обозначенный демо-профиль без пароля, редактирование, черновики и их отзыв, избранное. `/admin` описывает будущий интерфейс управления; реальные действия выключены.
- Адаптивное меню, клавиатурный фокус, ссылка перехода к содержимому, русские подписи и alt-тексты.

## Границы прототипа

Демо-сезон зафиксирован на 30 октября 2026 года. События, профили, имена, преподаватели, площадки и цены вымышлены. Стоковые фотографии не означают участие изображённых людей в Runway Models. Реальные референсы отделены от каталога.

Заявка не отправляется: сохраняется локальный черновик с именем, email, выбранным проектом, датой создания и статусом. Фотографии проверяются в браузере, но не загружаются и не сохраняются. Остальные поля формы — демонстрация будущего сценария. Пароли не запрашиваются. LocalStorage не является защищённым хранилищем или авторизацией. Данные одного браузера не синхронизируются с другими устройствами.

Серверные обработчики Next.js, настоящая авторизация, база данных, хранилище фото, роли, обработка заявок и уведомления относятся к следующему этапу. Для них потребуется переключить статический экспорт на серверный режим и добавить серверную проверку данных и прав.
