# Runway Models — локальная рабочая версия

Стек: Next.js 16.4.2 App Router, React 19.3, TypeScript, Material UI 9, Bootstrap 5; Node.js 24 LTS. Вход, анкеты, фотографии, избранное и административные решения хранятся на сервере. Внешнего сервиса или облачных ключей для локального запуска не нужно.

## Быстрый запуск

- Windows: `START-DEV.cmd` в папке проекта. Launcher при необходимости устанавливает зависимости, выбирает доступный loopback-порт и открывает браузер после успешного ответа сервера. Повторный запуск открывает уже работающий экземпляр.
- Терминал: `npm ci`, затем `npm run local`. Без автоматического браузера: `npm run local -- --no-open`.
- Обычный Next.js: `npm run dev`. Production: `npm run build`, затем `npm start`.
- `PORT` задаёт начальный порт; адрес берите из терминала. `localhost` и `127.0.0.1` имеют разные cookies: используйте один выбранный адрес последовательно.

Терминал оставьте открытым. Остановка — Ctrl+C. В отличие от прежней версии `npm start` запускает Next.js с API, а не статический сервер.

## Аккаунты и команда

Пользователь регистрируется с именем, email, городом и паролем. Обычная регистрация создаёт роль `member`. Пароли хешируются scrypt с индивидуальной солью, а сессии используют случайные токены в HttpOnly cookie; в SQLite сохраняются хеши токенов.

Первый администратор назначается локальным владельцем после регистрации:

```bash
npm run admin -- --email your-email@example.com
```

Откройте `/admin` после обновления страницы. Администратор видит анкеты и фотографии, принимает решение, оставляет ответ, назначает доступ сотрудникам. Последнего администратора удалить из роли нельзя. Снять роль другого сотрудника: интерфейс управления или `npm run admin -- --email employee@example.com --role member`.

Смена пароля выполняется из профиля с проверкой текущего пароля. Внешний email-сервис в локальную версию не подключён, поэтому отправки писем и восстановления через email нет.

## Анкеты

Типы: заявка модели, посещение открытого показа зрителем, запись на курс, запрос от бренда/фотографа. Заявка связана с выбранным событием, курсом или моделью. Общая анкета модели допускается отдельно от события.

Сохраняются контакты, город, возраст и параметры для моделей, комментарий/опыт, формат и дата проекта для сотрудничества, фотографии, дата создания, номер, статус и история решений. Модельные заявки — от 18 лет. Проверки выполняются в браузере и на сервере. Закрытые, прошедшие и отменённые события, истёкшие сроки и начавшиеся курсы недоступны для новой записи.

До 3 JPEG/PNG/WebP, до 5 МБ и 20 мегапикселей каждая. Сервер проверяет реальное содержимое, декодирует и сохраняет обработанный JPEG без EXIF. Загрузки не находятся в `public/`: доступ к каждой фотографии проверяется по владельцу или административной роли.

Повторная отправка одного запроса возвращает ту же сохранённую заявку. Повтор UUID с изменённым содержимым возвращает конфликт. Активные дубли на один проект блокируются. Для зрителей учитывается вместимость; при заполнении создаётся лист ожидания.

Участник видит свои заявки и может отозвать участие. Отозванные записи сохраняются в истории; администратор не может вернуть такую заявку в отбор. Статусы: отправлена, на рассмотрении, принята, отклонена, отозвана, лист ожидания. Успех на форме отображается только после сохранения данных и фотографий на сервере.

## Хранение и резервные копии

По умолчанию данные располагаются в `.runway-data/` рядом с `package.json`: `runway.sqlite` и `uploads/`. Папка исключена из Git. Для другого расположения задайте `RUNWAY_DATA_DIR` в окружении запуска или `.env.local`; примеры — в `.env.example`.

При резервном копировании остановите сервер и скопируйте всю папку данных вместе с фотографиями. Не удаляйте её при обновлении исходного кода. Потеря браузерного хранилища больше не удаляет отправленные анкеты или избранное аккаунта. Для переноса на другой компьютер нужны и исходники, и приватная папка данных.

Cookies привязаны к адресу браузера. Доступно только собственное содержимое; административные операции проверяют роль на сервере, ведётся журнал решений и назначения прав. Избранное гостя остаётся в браузере, после входа используется отдельный серверный список аккаунта.

## Проверки

```bash
npm run typecheck
npm run lint
npm run test:unit
npm run build
npm run test:integration
```

Unit-тесты проверяют даты и серверную валидацию. Интеграционный тест запускает production-сервер на свободном локальном порту с отдельной временной SQLite-базой и тестовыми фото. Основная папка `.runway-data` не используется. Проверяются вход, сессии, анкеты всех типов, валидация, файлы, повторы, доступ к чужим данным, модерация, роли, избранное и вместимость показа. Перед интеграционным тестом необходим `npm run build`.

## Содержимое сайта

На главной используются реальные фотографии Chico Lachowski, Jordan Barrett, Sean O’Pry и David Gandy как визуальные референсы. Они не являются участниками агентства. Каталог и программа событий пока содержат редакционные примеры, отмеченные в интерфейсе; сведения об авторах фото и лицензиях — `public/images/sources.json`.

Это локальная версия: сервер должен работать, чтобы посетители могли войти и отправить данные. Для публичного развёртывания нужны Node.js-хостинг с постоянным диском, HTTPS, резервное копирование и настройка владельца. Онлайн-платежи и внешние уведомления не реализуются локальной отправкой анкет.
